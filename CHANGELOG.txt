EB Games Auto Checkout — Changelog

1.9.0 — Discord Notifications
- Added optional Discord webhook configuration in the extension popup.
- Added a Test notification button to verify the webhook.
- Sends a notification for each product-add confirmation or unconfirmed result.
- Sends a cart quantity-preparation summary including failures and elapsed time.
- Webhook URL is stored in chrome.storage.local and is not embedded in source or release files.
- No checkout/payment confirmation is claimed; final checkout remains manual.
- Preserved parallel product tabs, success-confirmation tab closing, sequential cart refreshes, and existing cart logic.

1.8.0 — Stable Core
- Added guarded runs and deduplicated product results.
- Preserved parallel product tabs, sequential cart-refresh handling, and timing diagnostics.
